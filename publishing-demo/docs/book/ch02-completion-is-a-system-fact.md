第 2 章｜出版不是感觉，而是系统事实

当“完成”需要被讨论时，它就还没有完成。

2.1 为什么你总是在问：“这样算完成了吗？”

在写作与出版的过程中，
很多问题会反复出现：

这样算完成了吗？

还需要再改一轮吗？

要不要先发给别人看看？

等我有空再检查一遍行不行？

这些问题看似谨慎，
实际上都指向同一个事实：

完成的标准不在系统里，而在你心里。

而只要标准在“心里”，
它就一定会摇摆。

2.2 感觉，是人类最不可靠的完成标准

感觉有一个致命问题：
它会随时间、精力和情绪而变化。

刚写完时，你觉得哪里都不对

放几天后，你觉得好像也还行

临近截止日期时，你会突然觉得“够了”

同一份内容，
在不同时间点，
会被你给出完全不同的完成判断。

这不是你不专业，
而是感觉本身不具备稳定性。

2.3 系统事实，和人的叙述有什么不同？

我们来区分两种判断方式。

人的叙述型判断

“我已经检查过了。”
“逻辑上是完整的。”
“你只要理解我的意思就行。”

这些判断都有一个共同特征：

需要解释

依赖信任

无法复现

它们无法被第三方独立验证。

系统事实型判断

“命令执行完成。”
“系统没有报错。”
“产物已经生成。”

这些判断也有共同特征：

不需要解释

不依赖信任

可被任何人复现

它们是客观存在的事实。

2.4 出版系统只承认事实，不承认努力

出版系统并不关心：

你写了多久

你改了多少次

你付出了多少心血

它只关心一件事：

有没有一个可以被交付、被验证的结果。

这听起来很冷酷，
但它反而是一种解放。

因为一旦完成被定义为“系统事实”，
你就不再需要反复向自己证明：

“我是不是已经够努力了？”

2.5 为什么“系统”反而更有人情味

很多人会本能地抗拒“系统”这个词。

它听起来像：

冷漠

机械

没有人情味

但在出版这件事上，
系统恰恰是最公平的存在。

系统不会因为你是新手而放水，
也不会因为你经验丰富而抬高标准。

它只回答一个问题：

现在，是否满足完成条件？

2.6 当完成变成事实，焦虑会自然消失

一旦你拥有一个外在、稳定、不依赖情绪的完成标准，
写作者常见的几种焦虑会同时消失：

“我是不是还不够好？”

“别人会怎么看？”

“是不是还要再等等？”

因为你不再需要做判断。

判断，已经被系统做完了。

2.7 本章小结：完成不是判断，而是判定

这一章，我们只做了一件事：

把“完成”从主观判断，
移动到了客观判定。

从现在开始，请记住这个原则：

只要完成需要被解释，
它就还不是系统事实。

下一章，我们将第一次把这个原则
落到一个可以实际运行的最小系统中，
让“完成”不再是一个问题，
而是一个结果。
