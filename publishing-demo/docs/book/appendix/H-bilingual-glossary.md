附录 H｜中英双语核心术语表（出版级）

这一附录用于：英文版、教学引用、国际发布

中文术语	英文术语	标准释义
出版闭环	Publishing Loop	从输入到完成的完整路径
可验证	Verifiable	可被第三方独立确认
最小可验证出版闭环	Minimum Verifiable Publishing Loop (MVPL)	本书核心方法论
路线 A	Route A	MVPL 的最小可运行实例
完成	Completion	被系统确认的交付状态
系统事实	System Fact	不依赖解释的客观结果
通过 / 不通过	Pass / Fail	唯一评分方式
完成责任	Completion Responsibility	对交付结果负责的主体
出版产物	Publishing Artifact	系统生成的最终结果
自检	Quality Assurance (QA)	进入完成判定前的关卡
