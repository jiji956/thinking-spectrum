附录 F｜最小可验证出版项目结构

这一附录用于：模板仓库 / 教学起始包 / 新项目启动

F.1 最小结构（标准形态）
publishing-project/
├─ Makefile
├─ README.md
├─ docs/
│  └─ book/
└─ dist/


这是一个可运行、可验证、可教学的最小结构。

F.2 各部分职责说明
Makefile

系统入口

定义完成路径

禁止人工绕过

docs/book/

内容所在位置

不承担完成判定

可自由修改

dist/

完成事实所在地

不允许手动编辑

只由系统生成

F.3 结构设计原则

入口必须唯一

完成必须外显

人与系统职责分离
