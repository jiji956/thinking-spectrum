## Purpose
This appendix defines the release and versioning policy.

## Rule
A release may occur only after Route A completes successfully.

## Versioning
Semantic versioning is used: MAJOR.MINOR.PATCH.

## Normative Statement
A release is a verifiable event, not a declaration of readiness.
