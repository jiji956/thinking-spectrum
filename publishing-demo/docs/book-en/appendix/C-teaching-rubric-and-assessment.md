# Appendix C｜Teaching Rubric & Automated Assessment

> 🌏 **中文版本：**  
> 请参见 [`docs/book/appendix/C-teaching-rubric-and-assessment.md`](../../book/appendix/C-teaching-rubric-and-assessment.md)

This appendix defines a grading rubric and automated assessment model
for publishing education based on MVPL and Route A.

Assessment is binary: pass or fail.

## Grading Criteria

- Route A executes successfully
- QA passes automatically
- build completes
- system-generated artifacts exist

If any condition fails, completion is not verified.
