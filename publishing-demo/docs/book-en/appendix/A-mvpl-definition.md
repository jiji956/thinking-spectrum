## Definition

**MVPL (Minimum Verifiable Publishing Loop)** refers to:

> The smallest possible structure that allows a publishing outcome  
> to be completed, independently verified, and reproducibly confirmed,  
> without relying on personal judgment.

The purpose of MVPL is not to improve writing quality.  
Its sole purpose is to determine whether publishing has been completed.

## Required Components

Any system claiming to implement MVPL must include all four components below.

1. **Input**  
   Clearly identifiable source material.

2. **Rules**  
   Explicit, executable, deterministic completion rules.

3. **Output**  
   System-generated publishing artifacts.

4. **Verification**  
   Independent confirmation of completion.

Removing any single component renders completion unverifiable.

## What MVPL Does Not Evaluate

MVPL does not assess:
- quality
- originality
- style
- value

These belong after completion is confirmed.

## Normative Status

In this book, MVPL functions as:
- a normative definition
- a reference standard
- the baseline for all routes and checklists

## Summary (for Citation)

Publishing completion is a system-confirmed fact,  
not a subjective judgment.
