## Purpose
This appendix defines the authoritative failure taxonomy and handling
procedures for MVPL and Route A.

## Failure Classes
Failures occur at four stages:
- entry
- verification
- execution
- output

## Handling Rule
Failure requires correction and re-run.
Bypassing is prohibited.

## Normative Statement
Failure is the system enforcing the boundary of completion.
