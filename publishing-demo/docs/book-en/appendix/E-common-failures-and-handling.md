# Appendix E｜Common Failures & Handling

> 🌏 **中文版本：**  
> 请参见 [`docs/book/appendix/E-common-failures-and-handling.md`](../../book/appendix/E-common-failures-and-handling.md)

Failures are classified by where the publishing loop stops:
entry, verification, execution, or output.

Failure requires correction and re-run.
Bypassing is prohibited.
