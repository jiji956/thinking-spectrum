# Publishing Demo｜系统化出版操作系统（Demo）

> 一套 **可复制、可教学、可审计** 的现代出版方法  
>  
> 不是“怎么写得更快”，  
> 而是：**如何负责任地完成一次出版**。

---

## 这个仓库是什么？

这是《出版密码：从写作到发布》的 **官方教学 Demo 仓库**，  
用于展示一套完整的、可运行的出版系统：

- 从写作到发布
- 从 AI 辅助到人类责任
- 从单次产出到长期维护

你可以 **直接 clone、直接运行、直接教学**。

---

## 你将学到什么？

通过这个仓库，你将掌握：

- 如何用 **Make + 规则** 管理一本书
- 如何区分 **主权语言 / 派生语言**
- 如何让 **AI 参与但不替代责任**
- 如何用 **QA / Build / Release** 控制出版门槛
- 如何完成一次 **可追责的正式发布**

---
